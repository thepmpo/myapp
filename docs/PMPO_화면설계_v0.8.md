# PMPO 화면설계 (와이어프레임) v0.8

> v0.7에서 명칭 변경(커뮤니티→Circle, 정보게시판→Insights, 카테고리 영문화)과
> 카테고리 탭 UI 제거(사이드바 2depth로 이동)를 반영한 버전입니다.
> 변경 배경은 IA v0.3 참고.

---

## 화면 1. Circle 게시글 목록

*(구 "커뮤니티 게시글 목록")*

### 기능 명세

| 요소 | 동작 |
|---|---|
| 페이지 상단 소개 카피 | 제목("Circle") 아래에 짧은 설명 문구 노출 — 예: "질문하고 답하며 함께 성장하는 자리예요" (톤앤보이스 v0.2 참고) *(v0.8 신규)* |
| 정렬 드롭다운 | 최신순(기본) / 답변 없는 질문만 |
| "🙋 질문만 보기" 버튼 | 토글. 켜면 질문 태그된 글만 표시 |
| 카드 클릭 (제목/본문/이미지/인기댓글 영역 전체) | 게시글 상세로 이동 |
| + 글쓰기 버튼 | 비로그인 클릭 시 로그인 페이지로 이동 |
| 페이지네이션 방식 | 무한 스크롤 |
| 인기 댓글 미리보기 | 좋아요 수 기준 상위 2개 노출. 카드 타입(텍스트/이미지/텍스트+이미지) 상관없이 동일하게 적용 |

### 카드 타입별 레이아웃 정책

| 콘텐츠 구성 | 표시 방식 |
|---|---|
| 텍스트만 | 본문 일부만 텍스트로 노출 |
| 이미지/영상만 | 이미지 우선 크게 노출, 제목은 필수 입력 강제 (본문 텍스트는 없어도 됨) |
| 텍스트 + 이미지/영상 | 이미지 위, 본문 짧게 아래 |
| (공통) | 인기 댓글 최대 2개는 콘텐츠 타입과 무관하게 항상 동일 위치·형식으로 노출 |

### 상태별 화면

- **빈 상태**: "아직 게시글이 없어요. 첫 질문을 남겨보세요" + 글쓰기 버튼 강조
- **로딩**: 카드 3~5개 스켈레톤
- **에러**: 목록 로드 실패 시 재시도 버튼
- **무한 스크롤 로딩**: 하단에 스피너

### 데이터 소스

- `posts` 테이블 (제목, 본문, 질문태그 여부, 이미지 URL, 작성자, 작성시각)
- 좋아요/댓글 수: count 집계
- 인기 댓글: `comments` 테이블에서 좋아요 수 내림차순 상위 2개
- "미답변" 판정: 질문태그=true AND 댓글수=0

### 우선순위 / 버전

MVP (PRD Must-have 1, 4, 5번 직결) / v0.8

## 화면 2. Circle 게시글 상세

*(구 "커뮤니티 게시글 상세")*

### 기능 명세

| 요소 | 동작 |
|---|---|
| 좋아요 버튼 | 로그인 필요. 클릭 시 즉시 +1, 재클릭 취소. 비로그인 시 로그인 페이지 이동 |
| 팔로우 버튼 | 작성자 프로필/닉네임 영역에 위치. 로그인 필요 |
| 질문 태그 뱃지 | 작성 시 선택한 경우만 노출 |
| 댓글 입력창 | 비로그인 시 비활성화 + 안내 문구 |
| 등록 버튼 | 내용 없으면 비활성화 |
| 댓글 좋아요 | 댓글 1개당 좋아요 가능 |
| 댓글 구조 | 1depth 고정 (대댓글 없음 — PRD Out of Scope) |
| 공유 버튼 | 없음 (PRD Out of Scope) |

### 상태별 화면

- **빈 상태(댓글 0개)**: "아직 답변이 없어요. 첫 답변을 남겨보세요"
- **로딩**: 게시글/댓글 스켈레톤
- **에러**: 게시글이 삭제/존재하지 않을 때 안내 화면

### 데이터 소스

- 게시글: `posts` 테이블
- 댓글: `comments` 테이블 (게시글 id로 필터)
- 좋아요 수: `likes` 테이블 count
- 답변자 뱃지: 팔로우 30명 이상

### 우선순위 / 버전

MVP (PRD Must-have 1, 3번 직결) / v0.8

## 화면 3. Insights 목록

*(구 "정보게시판 목록")*

> **설계 결정**: Insights도 Circle과 동일하게 좋아요/댓글 소통 기능을 허용. 관리자만 글을 쓸 수 있다는 점(작성 권한)만 Circle과 다르고, 소비/반응 방식은 동일한 규칙(댓글 1depth, 대댓글·공유 없음)을 재사용.

### 기능 명세

| 요소 | 동작 |
|---|---|
| 카테고리 선택 | ~~페이지 내 탭~~ → **v0.8부터 좌측 사이드바 2depth 메뉴(Product/Trends/AI)로 이동, 상시 노출, 페이지 내 탭 UI는 제거** (IA v0.3 참고) |
| 아티클 카드 클릭 | 아티클 상세로 이동 |
| 좋아요/댓글 수 | 목록에 노출 |
| 조회수 | 상세 페이지 진입 시 +1. 로그인 유저는 user_id 기준, 비로그인은 브라우저 익명 ID(쿠키) 기준으로 24시간 내 중복 집계 제외 |

### 상태별 화면

- **빈 상태(해당 카테고리에 글 없음)**: "아직 등록된 글이 없어요"
- **로딩**: 카드 스켈레톤
- **에러**: 재시도 버튼

### 데이터 소스

- `articles` 테이블 (제목, 요약, 카테고리, 썸네일, 작성일, 조회수, 좋아요 수, 댓글 수)
- 현재 카테고리는 URL(`/insights/product` 등)로 결정, 페이지 내부 상태 아님 *(v0.8 변경)*

### 우선순위 / 버전

MVP (PRD Must-have 2번 직결) / v0.8

## 화면 4. Insights 아티클 상세

*(구 "정보게시판 아티클 상세")*

### 기능 명세

| 요소 | 동작 |
|---|---|
| 카테고리 뱃지 | 아티클 상단에 소속 카테고리(Product/Trends/AI) 표시 |
| 본문 | 관리자만 작성 가능 (일반 유저 작성 불가) |
| 조회수 | 목록/상세에 노출, 성공지표 3번(1주일 내 3천뷰)의 측정 기준. 유니크 판별은 화면 3 정책과 동일 |
| 좋아요 | 로그인 필요, Circle과 동일 규칙 |
| 댓글 | 로그인 필요, 1depth 고정, 대댓글/공유 없음 (Circle과 동일 규칙) |

### 상태별 화면

- **빈 상태(댓글 0개)**: "아직 댓글이 없어요"
- **에러**: 아티클이 삭제/존재하지 않을 때 안내 화면

### 데이터 소스

- `articles` 테이블
- `comments`, `likes` 테이블 (Circle과 동일 테이블 재사용, article_id로 구분)

### 우선순위 / 버전

MVP (PRD Must-have 2번 직결) / v0.8
