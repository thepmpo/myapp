# PMPO IA (정보구조) v0.2 — 확정본

---

## 1. 전체 사이트맵

```
홈 (랜딩)
├── 정보게시판 (관리자 발행 아티클)
│   ├── 프로덕트
│   │   ├── 아티클 목록
│   │   └── 아티클 상세
│   ├── PM/PO 트렌드
│   │   ├── 아티클 목록
│   │   └── 아티클 상세
│   └── AI
│       ├── 아티클 목록
│       └── 아티클 상세
├── 커뮤니티 (질문/답변, 단일 피드)
│   ├── 게시글 목록 (정렬/필터: 최신순, 답변 없는 질문만 보기)
│   │   └── 게시글 상세 (댓글, 좋아요)
│   └── 질문 글쓰기
├── 마이페이지 (로그인 시)
│   ├── 프로필 (뱃지, 팔로우 수)
│   └── 내 정보 수정
└── 로그인 / 회원가입
    ├── 로그인
    ├── 회원가입 (약관 동의 포함)
    ├── 비밀번호 재설정
    └── 로그아웃
```

### 설계 결정 및 근거

- **정보게시판 vs 커뮤니티 분리**: 정보게시판은 관리자만 발행(PRD Must-have 2), 커뮤니티는 유저의 질문 중심(Must-have 1)이라 목적이 다름. 각 화면에 다른 기능이 붙기 때문에 메뉴 단계에서부터 분리.
- **정보게시판 = 카테고리 3분류(프로덕트/트렌드/AI)**: 콘텐츠 소비 목적이 뚜렷해 초기부터 분류가 유효하다고 판단.
- **커뮤니티 = 카테고리 없이 단일 피드**: 초기엔 자유로운 질문/소통이 우선. 카테고리를 미리 강제하면 글쓰기 진입장벽이 생길 수 있어 데이터가 쌓인 뒤 재검토(백로그).
- **"라이브러리(북마크/모아보기)" 메뉴는 제외**: PRD Out of Scope 1번("프로필에서 게시글 모아볼 수 있는 기능")과 목적이 겹쳐 백로그로 이동.

## 2. 로그인 필요 여부

| 페이지/액션 | 비로그인 | 로그인 필요 |
|---|---|---|
| 정보게시판 목록/상세 보기 | ✅ | - |
| 커뮤니티 게시글 목록/상세 보기 | ✅ | - |
| 질문 글쓰기 | ❌ | ✅ |
| 댓글(답변) 작성 | ❌ | ✅ |
| 좋아요 누르기 | ❌ | ✅ |
| 팔로우 | ❌ | ✅ |
| 마이페이지 | ❌ | ✅ |

**설계 근거**: 정보 소비(읽기)는 진입장벽을 최소화해 트래픽 확보(PRD 목표)를 우선하고, 서비스 핵심 성공지표(답변률·응답시간)에 직접 연결되는 참여 행동(쓰기)만 로그인으로 제한.

## 3. 페르소나별 유저 플로우

```
[주니어 PM]
홈 → 커뮤니티 둘러보기/검색 → [원하는 답 있음] → 게시글 상세 확인 → 종료
                              → [원하는 답 없음] → 로그인 → 질문 글쓰기 → 답변 대기

[PM 취업 희망자]
홈 → 정보게시판 (트렌드 카테고리 확인) → 커뮤니티 검색 (취업 관련 질문)
   → [질문 없음] → 로그인 → 질문 글쓰기
   → [질문 있음] → 게시글 상세 확인 → 로그인 → 댓글로 추가 질문 → 답변 대기

[시니어 PM]
홈 → 정보게시판 (딥한 정보 확인) → 커뮤니티 (답변 없는 질문 필터로 확인)
   → 로그인 → 답변 작성 → 좋아요/팔로우 획득
```

**설계 근거**: 세 플로우 모두 "읽기는 비로그인, 쓰기 직전에만 로그인" 규칙을 동일하게 적용해 일관성 확보. 시니어 PM 플로우는 PRD Must-have 4번(답변 없는 질문 필터)이 있어야 실제로 작동 가능 — 이 기능이 빠지면 이 페르소나의 핵심 행동(답변하러 방문)이 성립하지 않음.

---

## 4. 백로그 (지금은 안 함, 기록만 해둠)

1. **라이브러리(북마크/모아보기) 메뉴** — PRD Out of Scope와 목적 중복
2. **커뮤니티 카테고리 분류** — 질문 수가 쌓인 뒤 실제 데이터 기반으로 재검토

---

## 5. 게시판 표현 형식

Medium 스타일 참고 — 리스트형(텍스트 중심) 게시판으로 확정. 카드형 스크롤 피드는 채택하지 않음.

## 다음 단계

이 IA v0.2를 기준으로 화면설계(와이어프레임)로 넘어갈 수 있는 상태입니다. 화면설계 단계에서는 각 화면(정보게시판 아티클 상세, 커뮤니티 게시글 상세/작성, 마이페이지 등)마다 기능 명세 + 상태(빈 상태/로딩/에러/데이터) + 데이터 소스 + 우선순위를 채워나갈 예정입니다.
