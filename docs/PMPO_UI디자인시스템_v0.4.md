# PMPO UI 디자인시스템 v0.4 — 레이아웃 여백 및 카드 스타일 보완

> v0.3(레이아웃/타이포/아이콘 기준) + 컬러 시스템 v1.1을 베이스로,
> 사이드바-본문 여백 부족과 카드 과다 강조 문제를 Medium 레퍼런스(https://medium.com) 기준으로 보완한 문서입니다.

## 배경

배포 후 확인 결과, 사이드바와 본문이 붙어 보여 답답하고, 게시글 카드마다 테두리+그림자가 항상 보여 화면이 복잡해 보이는 문제가 있었음. 컬러 시스템 v1.1의 "무채색 90%, 액센트는 정말 필요한 곳에만" 원칙이 레이아웃/카드 단계에서는 충분히 반영되지 않았던 것으로 판단.

## 1. 레이아웃 여백 규칙 (신규)

| 요소 | 규칙 |
|---|---|
| 사이드바 ↔ 본문 간격 | 넉넉한 여백 확보 (Medium 기준: 사이드바 폭 이후 본문 시작까지 충분한 gutter) |
| 본문 최대 폭 | 화면 전체 폭을 채우지 않고 가독성 있는 폭으로 제한, 좌우 여백 확보 |
| 우측 보조 사이드바 자리 | 지금은 비워둠 (추후 신규 기능으로 채울 예정 — UI디자인시스템 v0.3의 "인기 게시글 사이드바 백로그" 항목과 동일한 자리 재사용 가능) |
| 게시글/아티클 카드 간 수직 간격 | 기존보다 넉넉하게 확보, 카드가 촘촘하게 붙어 보이지 않도록 |

## 2. 카드(리스트 아이템) 스타일 변경

### 기존 (v0.3 기준)
- 카드마다 테두리 + `box-shadow: 0 1px 3px rgba(23,27,35,0.045)` 항상 노출

### 변경
- **기본 상태**: 테두리/그림자 없음. 카드 사이는 얇은 구분선(`--border`)으로만 구분되는 리스트 형태
- **Hover 상태**: 왼쪽에 2px `--accent` 라인만 나타남 (배경색 변화 없음)
- Circle 목록, Insights 목록 모두 동일 규칙 적용

> 이 변경은 컬러 시스템 v1.1의 "카드 Hover 테두리 시에만 accent 등장" 원칙(콘텐츠 카드 표 참고)을 레이아웃 구현에 정확히 반영한 것. 기존 구현은 이 원칙이 카드 자체가 아니라 그림자로 대체되어 있었음.

## 3. 적용 범위

Circle 게시글 목록, Insights 아티클 목록 두 화면에 우선 적용. 다른 리스트형 화면(팔로워 목록 등)은 이번 범위 밖이며 필요 시 별도 논의.
