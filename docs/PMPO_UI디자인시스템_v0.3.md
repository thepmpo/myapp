# PMPO UI 디자인 시스템 v0.3

> 컬러 확정. 브랜드 표기: **"The PMPO"**
> 데스크톱 기준 해상도: **콘텐츠 영역 1280px** (일반 노트북 뷰포트 기준)

## 컨셉

PM들이 실제로 쓰는 도구(스펙 문서, 포스트잇, 화이트보드)의 질감을 가져오되 과하지 않게. "가볍게 묻고 답하는 대화형 커뮤니티"라는 서비스 톤에 맞춰 딱딱한 SaaS 느낌은 지양.

## 타이포그래피

- **Space Grotesk** (500/700) — 게시글 제목, 브랜드명 등 헤더용. 지오메트릭 산세리프로 개성 있으면서 과하지 않음
- **Inter** (400/500/600) — 본문, UI 텍스트 전반. 가독성 우선
- **IBM Plex Mono** (400/500) — 작성자명, 시간, 조회수 등 메타 정보. "스펙 문서" 느낌으로 PM 대상 서비스에 맞는 디테일

## 시그니처 요소

**"질문있어요" 태그를 포스트잇처럼 모서리가 접힌 형태(clip-path)로 표현.** 사이트 전체에서 "누군가 묻고 있다"를 나타내는 단 하나의 상징으로 일관되게 사용.

## 컴포넌트 규칙

- 질문 태그가 있는 카드는 좌측에 앰버색 3px 보더로 구분 (질문/일반 글을 한눈에 스캔 가능하게)
- 인기 댓글 미리보기: 라벨("인기 댓글") 없이 별 아이콘(✦) + 닉네임 + 내용만 표시. 기준은 **좋아요 수 내림차순 상위 2개** (화면설계 문서와 동일)
- 버튼: 코발트 배경 + 흰 텍스트, 하단에 짙은 그림자 1px로 눌리는 느낌 표현
- **정보게시판 목록**: Medium 스타일 참고 — 텍스트(제목 크게+요약) 좌측, 썸네일 우측 배치. 날짜와 조회/좋아요/댓글 통계는 같은 줄에 붙이지 않고 **줄을 분리**해서 시각적 위계 구분
- 썸네일 플레이스홀더는 여러 액센트 컬러를 섞은 그라데이션 대신 **중립 톤 단색**으로 통일 (역할이 다른 강조색끼리 섞지 않는다는 원칙)
- **계정 탈퇴**: 화면에서 가장 눈에 덜 띄는 위치(하단 우측, 작은 링크)에 배치. 중요하지만 실수로 누르면 안 되는 액션이라 시각적 위계를 가장 낮게

## 데스크톱 레이아웃 (반응형)

- **1depth 메뉴(홈/커뮤니티/정보게시판)는 왼쪽 고정 사이드바**에 배치 (Reddit/Medium 참고). 상단 가로 메뉴 방식은 채택하지 않음
- **콘텐츠형 화면(커뮤니티 목록/상세, 정보게시판 목록/상세)**: 왼쪽 내비 + 중앙 본문. 목록류는 우측 보조 사이드바 추가(글쓰기 유도), 상세류는 읽기 폭(560px 내외)으로 좁혀서 중앙 배치
- **로그인 전 인증 화면(로그인/회원가입/비밀번호 재설정)**: 왼쪽 내비 없이 독립된 중앙 카드로 유지. 아직 로그인 전이라 앱 내부 메뉴를 보여줄 필요가 없고, 폼에 집중시키는 게 목적
- **로그인 후 폼 화면(마이페이지 프로필/정보수정/팔로워목록)**: 왼쪽 내비 + 중앙 카드
- 정렬/필터 드롭다운 등 컨트롤 요소는 데스크톱에서도 크기를 작게 유지 (본문 대비 과하게 커지지 않도록)
- **우측 사이드바 "인기 게시글" 기능은 백로그.** PRD에 없는 신규 기능이라 지금은 넣지 않고, "질문하기" 유도 박스만 우측에 유지

- **상세 화면 정렬**: 목록 화면과 동일하게 본문을 왼쪽 내비 바로 옆에서 시작하도록 좌측 정렬 (가운데 정렬 사용 시 목록→상세 전환할 때 본문 위치가 튀는 문제 있어 제외)

## 진행 상태

모바일 10개 화면 + 데스크톱 대표 패턴(커뮤니티 목록/상세, 정보게시판 목록, 로그인, 마이페이지) 방향 검증 완료. 나머지 데스크톱 화면(회원가입/재설정/정보수정/팔로워목록)은 위 규칙과 완전히 동일한 패턴이라 별도 목업 없이 이 문서 기준으로 적용 가능.

**컬러 값은 여전히 v0.1 임시값** — 사용자가 색상 리서치 완료하면, 그때 모든 화면의 색상 값만 일괄 교체하고 고정 이미지로 최종 내보내기 예정.

## 타이포그래피 (최종 — 렌더링 가능한 폰트로 교체)

- 한글/영문 본문·헤더: **Noto Sans CJK KR** (Bold 700 헤더, Medium/Regular 본문)
- 메타 정보(시간·작성자 등): **DejaVu Sans Mono**
- (참고: 초기 방향이었던 Space Grotesk/IBM Plex Mono는 실제 렌더링 환경에서 로드가 안 돼 실사용 가능한 폰트로 교체함)

## 아이콘 & 카드 스타일

- 좋아요/댓글 등 액션 아이콘은 이모지 대신 **선(stroke) 기반 SVG 아이콘**으로 통일 (더 정제된 느낌)
- 카드에 은은한 그림자 적용: `box-shadow: 0 1px 3px rgba(23,27,35,0.045)` — 테두리만으로는 밋밋해서 입체감 보완

## 진행 상태 (MVP 우선)

레이아웃·컬러·타이포·아이콘 방향 확정. **지금은 MVP 속도를 우선해 이 수준에서 개발 단계로 넘어가고, 디테일한 디자인 다듬기(마이크로 인터랙션, 세부 여백 등)는 이후 지속적으로 업데이트.** 모든 화면에 이 최종 스타일(폰트/아이콘/그림자)을 동일하게 적용.

## 다음 단계

이 톤·컴포넌트를 나머지 화면(게시글 상세, 정보게시판, 로그인/회원가입, 마이페이지 등)에 순차 적용. 데스크톱 레이아웃도 별도 작업 필요(화면설계 문서 참고).
