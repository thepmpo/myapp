# The PMPO Color System v1.1 — 확정본 (색상 절충안)

> v1.0(전면 다색 팔레트)에서 **색상 제한 방향**으로 재조정.
> 레퍼런스: Asterisk Magazine, Works in Progress — "본문/레이아웃은 거의 무채색, 색은 정말 필요한 곳에만" 원칙.
> 레이아웃, 타이포그래피, 컴포넌트 구조(포스트잇 질문 태그 모양 등)는 기존 v0.3 유지, **컬러 값만** 이 문서로 교체.

---

## 1. 방향 요약

- **본문/레이아웃**: 거의 무채색(차콜 텍스트 + 웜 페이퍼 배경)
- **포인트 컬러**: 1개 계열(코랄/레드)만 남기고, 버튼·링크·활성 탭 등 정말 중요한 액션에만 사용
- **상태 표시(질문/답변/에러)**: 배경색을 채운 "칩" 형태를 버리고, 아이콘/텍스트 색으로만 최소 표시 — 색은 "채우기"가 아니라 "작은 표식"
- **로고**: 유일하게 키 컬러(코랄)를 적극적으로 쓰는 자리로 확정 — 브랜드 인식은 로고가 담당, UI 전반은 절제

## 2. 최종 컬러 토큰

```css
:root {
  /* 무채색 - 화면의 대부분을 차지 */
  --ink: #262322;         /* 제목, 본문 */
  --ink-soft: #6B6460;    /* 메타정보, 설명 */
  --paper: #FAF8F6;       /* 페이지 배경 */
  --surface: #FFFFFF;     /* 카드, 입력창 */
  --border: #E5E1DD;      /* 테두리, 구분선 */

  /* 유일한 포인트 컬러 - 로고, 버튼, 링크, 활성 탭 */
  --accent: #C8464D;
  --accent-hover: #A83840;

  /* 상태 표시 - 배경 없이 텍스트/아이콘 색으로만, 최소 사용 */
  --question: #B8791C;    /* 질문있어요 - 배경 없음 */
  --answered: #3F7A5C;    /* 답변완료 - 배경 없음 */
  --error: #B8382E;       /* 폼 검증 등에만, 배경 없음 */
}
```

## 3. v1.0 대비 변경점

| 영역 | v1.0 | v1.1 (현재) |
|---|---|---|
| 브랜드 톤 수 | 4개(코랄/액션레드/다크레드/파우더핑크) | 2개(accent/accent-hover) — 코랄은 로고 전용, UI는 accent 1톤 |
| 태그/필터 선택 상태 | 배경색 채운 칩(파우더핑크) | 배경 없이 얇은 액센트 라인 또는 볼드 텍스트만 |
| 사이드바 선택 | 배경+텍스트 색 조합 | 왼쪽 얇은 액센트 라인 + 텍스트 볼드 |
| 질문 태그 좌측 보더 | 3px 앰버 블록 | 1.5~2px, 톤도 더 muted(#B8791C 계열)하게 |
| 질문/답변 상태 | 배경+텍스트 칩 | 아이콘/점 색만, 배경 없음 |
| 에러 | 배경+텍스트 칩 | 텍스트만, 배경 없음 (폼 검증 등 국소적 사용) |
| 로고 | B안(차콜+코랄 포인트) 유지 | **변경 없음 — 그대로 유지**, 유일하게 색을 적극 쓰는 자리 |

## 4. 화면 요소별 적용 규칙

### 사이드 내비게이션
| 상태 | 표시 |
|---|---|
| 기본 | `--ink-soft` 텍스트/아이콘, 배경 없음 |
| Hover | `--ink` 텍스트, 배경 없음 또는 아주 옅은 회색 |
| 선택 | 왼쪽 2px `--accent` 라인 + `--ink` 볼드 텍스트 (배경 없음) |

### 주요 버튼 (글쓰기, 질문하기, 팔로우 등)
| 상태 | 배경 | 텍스트 |
|---|---|---|
| Default | `--accent` | `#FFFFFF` |
| Hover | `--accent-hover` | `#FFFFFF` |
| Disabled | `--border` | `--ink-soft` |

→ 유일하게 색이 채워지는 UI 요소. 그 외 버튼(취소, 보조 액션 등)은 무채색 아웃라인.

### 탭/필터
| 요소 | 표시 |
|---|---|
| 기본 탭 | `--ink-soft` 텍스트 |
| 활성 탭 | `--ink` 텍스트 + `--accent` 밑줄 |
| 선택된 필터 | 배경 없음, `--accent` 텍스트 또는 아이콘만 |

### 콘텐츠 카드
| 요소 | 표시 |
|---|---|
| 배경/테두리 | `--surface` / `--border` |
| Hover 테두리 | `--accent` (이때만 색 등장) |
| 질문 태그 카드 좌측 보더 | `--question` 계열, 1.5~2px (기존 3px보다 얇게) |

### 질문/답변/에러 상태
- **배경색 사용하지 않음.** 아이콘 색 + 텍스트 색으로만 표시 (예: 🙋 아이콘 + `--question` 텍스트)
- 칩/배지 형태가 필요하면 배경은 무채색(연회색), 텍스트/아이콘만 상태색

### 로고
- 기존 결정(B안) 유지: "The PMPO" 전체 `--ink`, 코랄(`--accent`)은 점/사각형/밑줄 포인트로만
- 로고는 이 시스템에서 **유일하게 색이 적극적으로 등장하는 자리**라는 점을 명확히 인지하고 사용

## 5. 사용 비율 원칙 (재조정)

| 영역 | 비율 |
|---|---:|
| 무채색(페이퍼/화이트/차콜/그레이) | 90% 이상 |
| 포인트 컬러(accent) | 5% 이내, 버튼/링크/활성탭에 집중 |
| 상태색(질문/답변/에러) | 극소량, 텍스트·아이콘 단위 |

*(v1.0의 코랄 8% 기준보다 더 엄격하게 조정)*

## 6. 적용 순서

1. 전체 배경/본문을 무채색 톤으로 정리
2. 기존 다색 칩(태그, 필터, 상태 배지)에서 배경색 제거 → 텍스트/아이콘 색만 남기기
3. 버튼을 accent 1톤으로 통일 (기존 액션레드/다크레드 2톤 유지, 나머지 코랄/핑크는 제거)
4. 사이드바 선택 상태를 배경색 방식에서 라인 방식으로 변경
5. 질문 태그 좌측 보더 두께/톤 조정
6. 로고는 기존 B안 그대로 유지 (변경 없음)
