## 화면 6. 회원가입 — 검증 로직 보완

기존 v0.7 명세("이메일 중복, 비밀번호 규칙, 닉네임 중복 검증 후 계정 생성")를 아래와 같이 구체화.

| 요소 | 동작 |
|---|---|
| 이메일 중복 확인 | 입력 완료(포커스 아웃) 또는 제출 시 확인, 중복이면 인라인 에러 |
| 비밀번호 확인란 | 비밀번호 입력란 아래 확인용 입력란 추가, 두 값 불일치 시 인라인 에러 |
| 비밀번호 조합 규칙 | **8자 이상 + 영문/숫자 조합 필수** (초안 기준, 필요 시 조정) |
| 가입하기 버튼 활성화 조건 | 필수 약관 전체 체크 **AND** 이메일 중복 없음 **AND** 비밀번호 규칙 통과 **AND** 비밀번호 확인 일치 — 모두 충족해야 활성화, 하나라도 미충족이면 비활성화(회색) 유지 |

### 상태별 화면 (추가)

- 이메일 중복: "이미 가입된 이메일이에요" 인라인 에러
- 비밀번호 규칙 미달: "8자 이상, 영문과 숫자를 함께 써주세요" 인라인 에러
- 비밀번호 확인 불일치: "비밀번호가 일치하지 않아요" 인라인 에러

| 요소 | 동작 |

## 화면 11. 관리자 페이지 (신규)

> 기존엔 `admin/page.tsx`에 Insights 글쓰기 폼이 인라인으로 있었는데, 이번에 별도 관리자 전용 화면으로 분리.

### 기능 명세

| 요소 | 동작 |
|---|---|
| Insights 글 작성 | 카테고리(Product/Trends/AI) 선택 포함 (화면설계 v0.8에서 이관된 `/insights/new`와 연동) |
| Insights 글 수정 | 기존 아티클 목록에서 선택해 수정 |
| Insights 글 삭제 | 확인 모달 후 삭제 |
| 접근 권한 | 관리자 계정만 접근 가능, 일반 유저는 접근 시 홈으로 리다이렉트 |

### 우선순위 / 버전

MVP 이후 추가 범위 (PRD Must-have 2번과 연결되지만, 최초 MVP 이후 운영 편의를 위한 보완) / v0.9
